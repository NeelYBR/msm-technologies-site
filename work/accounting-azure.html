The challenge

A seven-year-old on-site server running practice software and files, out of warranty, slow over VPN and a single point of failure in tax season.

What we did

Moved practice software to an Azure virtual desktop, files to SharePoint with a sensible structure, and decommissioned the server. Added Intune, MFA and Microsoft 365 backup.
